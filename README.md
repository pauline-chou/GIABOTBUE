# GIABOTBUE
You have to change the following contents of settings.py:

LINE_CHANNEL_ACCESS_TOKEN = 'Channel access token'

LINE_CHANNEL_SECRET = 'Channel secret'

GOOGLE_PLACES_API_KEY = 'google place api'
